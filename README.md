# At Street.Coffee — website

Proposta de novo site para a At Street.Coffee (Porto · Matosinhos · São Paulo).

Página única, sem dependências de build: abre `index.html` num browser ou publica a pasta em qualquer alojamento estático (GitHub Pages, Netlify, etc.).

## Secções
- **Início** — logótipo, lema em néon, destaques do menu e fotos das lojas
- **Menu** — carta Winter 25/26 com filtros, pesquisa e "só gelados"
- **Café** — Coffee Collection Summer 2026
- **Lojas** — Clérigos, Foz, Matosinhos e Itaim Bibi
- **Merch** — produtos com fotos e variantes
- **Club** — formulário de inscrição (pré-visualização, não envia dados)

Idiomas: PT / EN. Responsivo e com modo claro/escuro automático.
